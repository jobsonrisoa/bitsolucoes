# Contributing to Átrio

We use Conventional Commits. Please ensure your commit messages follow this format:
`<type>[optional scope]: <description>`

## Branch Flow

1. Create a branch from `main`: `feature/your-feature` or `fix/your-fix`
2. Make changes
3. Run tests and linting
4. Open a Pull Request to `main`

## PR Checklist

- [ ] Code follows formatting guidelines
- [ ] Tests added/updated
- [ ] Documentation updated
- [ ] Commit message follows Conventional Commits
